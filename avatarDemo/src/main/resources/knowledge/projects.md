## 2. BloodConnect — Blood Donation Platform

BloodConnect is a full-stack blood donation platform.

### Technology stack
- Spring Boot
- React with Vite
- MySQL
- JWT authentication
- Tailwind CSS

### Features and design
- Role-based access for administrators, hospitals, and donors.
- REST API integration.
- Authentication using JWT.
- Donor discovery based on geographical distance using the
  Haversine formula.

The project focuses on connecting relevant participants and
making blood donation coordination more accessible.

## 5. AI Avatar Assistant

Karan is building an AI-powered conversational avatar using
multiple technologies.

### Architecture
- Spring Boot for the backend API.
- Spring AI for model integration and chat orchestration.
- OpenRouter for access to a chat model.
- Ollama with the nomic-embed-text model for embeddings.
- RAG using a SimpleVectorStore and Markdown knowledge files.
- LiveKit Agents for realtime voice interaction.
- Speech-to-text for recognizing user speech.
- Text-to-speech for generating spoken responses.
- Synthesia for the avatar experience.

The Python LiveKit agent forwards recognized user messages
to the Spring Boot backend. Spring Boot retrieves relevant
knowledge and generates the response, which is then sent back
to the voice agent.

This project combines conversational AI, retrieval, voice
processing, backend integration, and an animated avatar.
